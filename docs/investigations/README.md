# Investigations

Write-ups of technical investigations: what was seen, how it was measured, what was ruled out and what is left open. A note records evidence, not rules: what the project does about a finding goes into `DESIGN.md` (a 6.7 loose end, a 6.2 question) and is decided there. How one runs: `docs/agent-notes/working-agreements.md` "Debugging and investigations".

One line per note below: its file, what it looks into and when, whether it is open, paused or done, and the `DESIGN.md` section or question it serves. A paused note's "Picking this up" list is the next agent's start.
