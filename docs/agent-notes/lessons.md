# Lessons waiting for a retro

A package's close adds at most three lines here, and any other routine session (a design stage, a feedback pass, a run) at most two; neither changes a skill, note or tool for them. Lines are added with `python tools/docs.py lesson add "<line>"`. A retro (the lg-package skill's retro stage), run when the owner asks, about every five closed packages, works them into the procedure and removes them.

Last retro: none yet. A retro records here its date, the command that measured its sessions, and the figures it read (sessions, cost, requests, peak context).

Each line: `- {{PREFIX}}-nnn: <what cost turns or went wrong, with a count> → <the change proposed>`.
