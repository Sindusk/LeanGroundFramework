# {{PROJECT}} — Design Questions

**Working document, not authority.** A place to answer design questions in batches, away from the chat. The rules live in `DESIGN.md`; nothing here is a rule until it has been consolidated there.

**How it works**

1. An agent writes a round: each question as Explanation, Gap, Options and Recommendation, with an empty **Response**.
2. The owner fills in the Responses, in any order and over any time, alone or with someone else. A one-line answer is enough ("Recommendation", "Option b", "Option a, but ..."); so is "not yet" or "discuss".
3. An agent brings the answers back: each becomes a decision under its question in `DESIGN.md` 6.2, then is consolidated into the design and `design-history.md` when the owner asks. Answered questions are removed from this file; unanswered ones stay for the next round.

Question numbers are `DESIGN.md`'s permanent numbers, so "Q12" means the same thing everywhere.
