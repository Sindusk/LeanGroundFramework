# Agent entry point

Whichever agent you are, read [`CLAUDE.md`](CLAUDE.md) before inspecting, editing, building or testing this repository. It is the shared startup contract, and its routing list names what each kind of work needs. If your harness already loaded `CLAUDE.md`, don't read it again. If your harness has no skills, a skill `CLAUDE.md` names is `.claude/skills/<name>/SKILL.md`: read it and follow it.

Do not add project rules here. Put them in the document `CLAUDE.md` names, so every agent receives the same instruction and no copy can drift. **Rules name no agents.**
