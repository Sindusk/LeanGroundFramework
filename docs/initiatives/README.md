# Initiative working documents

One file per Initiative whose design outgrew a few questions in `DESIGN.md` 6.2, named for the Initiative (search-filters.md for Search Filters) and headed "working document, not authority". Its questions use `DESIGN.md`'s permanent numbers. Accepted decisions are consolidated into `DESIGN.md` and `design-history.md` when the owner asks; when the Initiative closes, the file moves unedited to `docs/archive/initiatives/`. How one is opened and run is the design skill's.
